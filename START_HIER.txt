INJEKTO-LOG - FINALES GITHUB-PAKET - VERSION 1.1.1

1. Dieses ZIP vollstaendig entpacken.
2. Den INHALT des Ordners injekto-log in ein leeres GitHub-Repository
   mit Branch main uebertragen, vorzugsweise mit GitHub Desktop.
   package.json und .github muessen direkt im Repository liegen.
3. Fuer die Website: Settings > Pages > Source > GitHub Actions.
4. Unter Actions den Workflow "Injekto-log auf GitHub Pages" starten.
5. Nach erfolgreichem Lauf die angezeigte Website-Adresse oeffnen.

Die ausfuehrliche Anleitung steht in README.md.
index.html nicht direkt doppelklicken: Dies ist ein React-Quellprojekt.
Lokal mit Node.js 24 und pnpm starten (siehe README).

Die App speichert Protokolle nur im jeweiligen Browser. Bestehende Daten
vor dem Wechsel als JSON exportieren und an der neuen Adresse importieren.
Dieses ZIP enthaelt keine persoenlichen Protokolle und keine Zugangsdaten.
